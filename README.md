# Ai-automation-portfolio-SivachandranMuthusamy
# Portfolio: AI and automation in banking technology

One-page portfolio for Sivachandran Muthusamy.

- `index.html` is the whole site, with no build step and no dependencies.
- It includes a request-triage prototype. The prototype is **rule-based, not an LLM**, and uses synthetic data only. It masks emails and long numbers, then classifies by keyword.
- Case studies use figures from the CV only. No employer-confidential detail.

## Run locally
Open `index.html` in a browser.

## Host free on GitHub Pages
Repo Settings → Pages → Source: deploy from branch `main`, folder `/ (root)`.
